# Control Statements

## Overview

Control statements are used to control the flow of execution of a Python program.

The basic control flow introduced in the  programs is:

```text
Sequence → Selection → Iteration
```

---

# Sequence

In **Sequence**, statements are executed one after another in the order in which they are written.

It represents the normal flow of execution of a program.

### Example

```python
print("First statement")
print("Second statement")
print("Third statement")
```

### Execution Flow

```text
First statement
      ↓
Second statement
      ↓
Third statement
```

Each statement is executed sequentially.

###  Example

```python
print("Jay Ganesh...")
print("Jay Ganesh...")
print("Jay Ganesh...")
print("Jay Ganesh...")
print("Jay Ganesh...")
```

The statements are executed from top to bottom.

---

# Selection

Selection is used when a program needs to make a decision based on a condition.

The programs introduce:

- `if`
- `if-else`
- `if-elif-else`

---

## `if` Statement

The `if` statement executes a block of statements when the specified condition is true.

### Syntax

```python
if condition:
    statement
```

### Example

```python
Age = 20

if Age >= 18:
    print("You are eligible")
```

If the condition is true, the statements inside the `if` block are executed.

---

## `if-else` Statement

The `if-else` statement provides two possible execution paths.

### Syntax

```python
if condition:
    statement
else:
    statement
```

### Example

```python
print("Enter your age : ")
Age = int(input())

if Age < 18:
    print("Sorry you are not allowed")
else:
    print("Welcome to the movie")
```

If the condition is true, the `if` block is executed.

If the condition is false, the `else` block is executed.

---

## `if-elif-else` Statement

The `if-elif-else` statement is used when multiple conditions need to be checked.

### Syntax

```python
if condition1:
    statement
elif condition2:
    statement
else:
    statement
```

### Example

```python
print("Please enter your age : ")
Age = int(input())

if Age <= 5:
    print("Free entry")
elif Age > 5 and Age <= 18:
    print("Ticket price : 900")
elif Age > 18 and Age <= 40:
    print("Ticket price : 1200")
else:
    print("Ticket price : 500")
```

The conditions are checked from top to bottom.

The block associated with the first true condition is executed.

---

# Iteration

Iteration is the process of executing a block of statements repeatedly.


- `while` loop
- `for` loop

---

## `while` Loop

The `while` loop repeatedly executes a block of statements while its condition is true.

### Syntax

```python
while condition:
    statement
```

### Example

```python
Count = 0

while Count < 5:
    print("Jay Ganesh...")
    Count = Count + 1
```

### Execution Flow

```text
Initialize Count
       ↓
Check condition
       ↓
Condition True
       ↓
Execute statements
       ↓
Update Count
       ↓
Check condition again
       ↓
Condition False
       ↓
Loop terminates
```

---

## `for` Loop

The `for` loop is used to iterate over a sequence or a range of values.

### Syntax

```python
for variable in sequence:
    statement
```

### Example

```python
for i in range(5):
    print("Jay Ganesh...")
```

The loop executes for each value generated by `range(5)`.

---

## `for` Loop with Loop Variable

The loop variable can be used inside the loop body.

### Example

```python
for i in range(5):
    print(i)
    print("Jay Ganesh...")
```

### Output

```text
0
Jay Ganesh...
1
Jay Ganesh...
2
Jay Ganesh...
3
Jay Ganesh...
4
Jay Ganesh...
```

---

# `range()`

The `range()` function represents a sequence of numbers and is commonly used with the `for` loop.

### Examples

```python
range(5)
```

```python
range(0, 5, 1)
```

`range(5)` generates values starting from `0` and continuing up to, but not including, `5`.

### Example

```python
for i in range(5):
    print(i)
```

### Output

```text
0
1
2
3
4
```

---

## Forms of `range()`

The  programs also demonstrate different forms of `range()`:

```python
range(stop)
```

```python
range(start, stop)
```

```python
range(start, stop, step)
```

### Examples

```python
range(5)
```

```python
range(1, 7)
```

```python
range(3, 9, 2)
```

The `stop` value is not included in the generated sequence.

---

# Sequence vs Selection vs Iteration

| Control Flow | Purpose | Examples |
|--------------|---------|----------|
| Sequence | Execute statements in order | Normal statements |
| Selection | Make decisions | `if`, `elif`, `else` |
| Iteration | Repeat statements | `while`, `for` |

---

# Important Points

- Sequence executes statements in the order in which they are written.
- Selection is used for decision making.
- `if` checks a condition.
- `else` provides an alternative execution path.
- `elif` allows additional conditions to be checked.
- Iteration is used to repeat a block of statements.
- `while` repeatedly executes statements while its condition is true.
- `for` is used to iterate over a sequence or range.
- `range()` generates a sequence of numbers.
- The `stop` value of `range()` is not included.
- Indentation defines the block of statements in Python.
